# CalcArt ✏️

**Demo:** [https://joelsiervas.online/calculadora-24358/](https://joelsiervas.online/calculadora-24358/)

Calculadora de estilo dibujado a mano, desarrollada con React y TypeScript.

## Instalación

```bash
bun install
```

## Ejecutar la aplicación

```bash
bun run dev
```

La aplicación estará disponible en [http://localhost:5173](http://localhost:5173).

## Ejecutar las pruebas

```bash
bun test
```

## Ejecutar Storybook

```bash
bun run storybook
```

Storybook estará disponible en [http://localhost:6006](http://localhost:6006).

## Lint

```bash
bun run lint
```

## Sobre las ilustraciones

Todos los elementos visuales de la aplicación fueron dibujados a mano en Procreate y exportados como PNG a `public/assets/`. El cuerpo de la calculadora, el marco del display y el fondo de la página son ilustraciones propias. La aplicación utiliza colores CSS como fallback en su ausencia, aunque la identidad visual del proyecto proviene de dichos dibujos.

## Stack

- React 18 + TypeScript
- Vite + Vitest
- ESLint (JavaScript Standard Style)
- Storybook 8
- Bun como package manager
